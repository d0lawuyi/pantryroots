# PantryRoots

One pantry. Every tribe. Scan what you have, discover how different peoples cook it, and get help when you're missing an ingredient.

## Features
- Pantry photo scan & UPC barcode lookup (Open Food Facts API)
- Explore by people/tribe: Yoruba, Igbo, Hausa-Fulani, Akan, Wolof, Amhara, Swahili, Kikuyu, Luo, Baganda, Somali & more
- Battle of the Food Tribes: Jollof Wars with live Elo leaderboard, Fufu vs Ugali vs Sadza, Groundnut Stew Battle
- SOS Mode: Broke (substitute), Authentic (find ethnic store), Fastest (sub + delivery)
- Pantry Circle: neighbor borrowing before delivery
- Recipe detail with in-pantry / missing ingredient check

## Tech Stack
React + TypeScript + Vite + Tailwind CSS, Lucide icons, localStorage persistence

## CI/CD
GitHub Actions builds on every push/PR to `main`. Vercel auto-deploys production on successful build.
