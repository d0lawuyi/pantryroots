# PantryRoots

Cook from your pantry across West and East African food traditions, grouped by the peoples who cook them. A Kitchen Concierge, built on **Meta's Muse models via the Meta Model API**, scans a photo of your shelf, tells you what you can make, and when you're out of something it finds a swap, the nearest open shop and an Instacart cart.

## Stack

- Vite + React + TypeScript, plain CSS design system (see `DESIGN.md`)
- **AI: Meta Muse Spark (`muse-spark-1.3`, fallback `muse-spark-1.1`) through the Meta Model API** (`https://api.meta.ai/v1`, OpenAI-compatible chat completions with vision and tool calling)
- `/api/concierge` — Vercel function with no dependencies. A tool-calling agent: Muse reads pantry photos, ranks dishes, writes labeled AI dishes, and calls our tools for swaps, stores and delivery
- `/api/recipe` — Muse turns a spoken family recipe into a structured recipe card
- `/api/macros` — Muse estimates per-serving macros (labeled as estimates)
- Live data: **Google Places API (New)** for shops, **Google Routes API** for drive time, **Instacart Developer Platform** for carts

## Run it

```bash
npm install
npm run dev          # UI only; the concierge falls back to built-in answers
npm test             # recipe matching and sample pantry regression checks
npm run typecheck
npm run build
npx vercel dev       # UI + /api/concierge with your .env.local keys
```

Copy `.env.example` to `.env.local` and fill in the keys. Only `META_API_KEY` is required.

New visitors start with an empty pantry. **Try sample pantry** loads 11 demo ingredients; **Start my own pantry** clears that unchanged sample so you can enter your own food. Existing saved pantry contents remain on the device. The original 11-item sample is recognized regardless of item order and case.

All 23 curated dishes include suggested amounts for four servings in both the recipe sheet and cooking preparation list. Ingredient names remain the shared keys for pantry matching and shopping lists; quantities are display metadata. Water, advance preparation notes and optional serving extras appear separately. Optional extras do not block a match or enter the shopping list automatically. These amounts are suggested starting points, not kitchen-tested formulations. See `docs/recipe-audit.md` for scope and references.

## How the concierge works

Every answer is generated by Meta Muse Spark; the panel credits the model on each reply ("Answered by Meta Muse Spark 1.3"). `GET /api/concierge` shows the live provider and model.


| Tool | What it does |
|---|---|
| `show_pantry_scan` | Model looks at the photo and lists ingredients, flagging uncertain ones |
| `match_dishes` | Ranks our 23 curated dishes against the pantry |
| `suggest_ai_dish` | Adds dishes from other traditions, labeled **AI-written** |
| `find_substitute` / `show_substitute` | Our substitute notes first; AI only fills gaps |
| `find_stores` | Google Places + Routes: open shops, distance, drive time, closing time |
| `create_cart` | Instacart shopping-list link |

Every tool has a fallback: Maps search, Instacart search, or built-in answers if the AI is down. **Demo mode** (checkbox in the panel) plays sample answers and works offline. Store names are prefixed "Sample:".

## Macros and MyFitnessPal

MyFitnessPal has had no public API since 2019, so PantryRoots doesn't connect to MFP accounts. Copy your daily targets in from MFP's Goals screen; each dish has "Copy for MyFitnessPal", which gives a line to paste into Quick Add. Macros are AI estimates for a typical home serving, not measurements, and stay on your device.

## Demo script (about 60 seconds)

1. Open the Cook page. The concierge sits on the right on desktop; on a phone, tap **Ask**.
2. Tap **Scan my pantry** and take a photo of a shelf. Untick anything wrong, then **Add to pantry**. The Cook page match meters fill in behind the panel.
3. Type **"Something Caribbean with what I have"** to get an AI-written dish card. Open it to see the label.
4. Type **"I'm out of palm oil"** to get a swap card, the nearest open shops with drive time, and an Instacart cart.
5. Bad wifi? Tick **Demo mode** and run the same steps.
